# Changelog

## [1.3.0] - 2024-09-01

### Added
- **Вкладка Статистика департамента**
  - Новая вкладка на странице департамента с аналитикой ответов
  - Переключатель периодов: 1 день / 7 дней / 30 дней
  - Карточки с метриками:
    - Всего ответов за выбранный период
    - Количество активных форм
    - Среднее количество ответов в день
  - Детальная статистика по каждой форме с визуальными полосами прогресса
  - Адаптивный дизайн и поддержка темной темы

- **Многострочные описания полей формы**
  - Возможность добавлять многострочное описание к каждому полю
  - Поддержка переносов строк (красных строк)
  - Автоматическое изменение размера textarea при вводе
  - Отключена возможность ручного изменения размера текстового поля
  - Корректное отображение описания в форме с сохранением форматирования

- **Placeholder для текстовых полей**
  - Возможность задавать placeholder текст для полей короткого и длинного текста
  - Поле отображается рядом с полем описания для удобства

- **Поле Discord ID в формах**
  - Добавлено специальное поле для ввода Discord ID пользователей
  - Автоматическая валидация формата Discord ID

- **Анимированный спиннер загрузки**
  - Заменены статичные заглушки "Загрузка..." на анимированный спиннер
  - Улучшенный пользовательский опыт при загрузке данных

### Improved
- **Редактор полей формы**
  - Улучшена верстка полей "Описание" и "Placeholder"
  - Поля расположены в одну строку для экономии пространства
  - Добавлены четкие метки над каждым полем
  - Увеличены отступы и размеры полей для удобства ввода
  - Поле описания теперь выровнено по верхнему краю с другими элементами

- **Стили описания в формах**
  - Улучшена читаемость текста описания (более темный цвет)
  - Светлая тема: #475569 (было #64748b)
  - Темная тема: #a8b3c0 (было #94a3b8)

- **Темная тема**
  - Добавлена полная поддержка темной темы для всех новых компонентов
  - Статистические карточки, спиннер загрузки и все новые элементы

### Technical
- Добавлен API endpoint `GET /api/departments/:id/stats?days=N`
  - Возвращает статистику ответов за указанный период
  - Агрегация данных по формам департамента
  - Подсчет активных форм и общего количества ответов
- Добавлена функция `autoResizeTextarea()` для автоматического изменения размера textarea
- Добавлена функция `formatDescription()` для корректного отображения многострочного текста с экранированием HTML
- Обновлены стили в `forms.css`:
  - Добавлены классы для статистики (.stats-grid, .stats-card, .stats-form-item)
  - Добавлены классы для спиннера загрузки (.loading-container, .loading-spinner)
  - Обновлены стили описания полей (.form-field__description)
- Версия CSS обновлена до v19

### Fixed
- Исправлено отображение переносов строк в описаниях полей формы
- Исправлена обработка пустых значений в полях описания и placeholder
- Исправлено экранирование HTML в описаниях для предотвращения XSS
